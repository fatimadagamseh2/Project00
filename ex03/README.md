# Project 00: Linux + Git + GitHub

## Overview

This project introduces the basic skills needed to work with Linux, Git, and GitHub. It covers terminal navigation, file manipulation, version control, remote repositories, and secure authentication.

## Exercises

### Exercise 00 — Terminal Navigation & Directories

This exercise focuses on navigating the Linux filesystem using the terminal and creating a structured project directory.

### Exercise 01 — File Manipulation & Text Streams

This exercise practices creating, writing, copying, moving, and deleting files using shell commands and redirection.

### Exercise 02 — GitHub Repository

This exercise introduces Git version control and GitHub. A local repository is created, committed, connected to GitHub, and pushed to a public repository.

### Exercise 03 — Project & README

This exercise focuses on documentation and the Git edit-add-commit-push workflow.

## Why Git Makes Development Easier

Git makes development easier because it keeps a history of changes to a project. If something goes wrong, developers can look at previous commits and understand what changed.

Git also helps protect code by keeping different versions of the project instead of relying on only the latest copy. Developers can work on changes and save them as separate commits.

For teams, Git makes collaboration easier because different developers can work on the same project, share their changes, and keep track of who changed what.

## Git Workflow

The basic workflow used in this project is:

1. Edit a file.
2. Use `git add` to stage the changes.
3. Use `git commit` to save the changes in the local repository.
4. Use `git push` to send the commit to GitHub.
